# URL Shortener

Small URL shortener built for a technical challenge. Read `.specify/memory/constitution.md` first: it overrides default behavior.

## Stack
- Node.js + TypeScript, Fastify, SQLite, Vitest
- UI: React + Vite
- Package manager: bun (never npm, yarn or pnpm)

## Where things live
- Spec, plan, tasks: `specs/` (generated by Spec Kit)
- ADRs: `docs/adr/`
- Process log and decisions: `PROCESS.md`

## Commands
Every package defines:
- `bun run test`: runs `vitest run` (never watch mode, the hook would hang)
- `bun run typecheck`: runs `tsc --noEmit`
- `bun run dev`: starts the app locally

## Workflow rules
- Spec phase: Spec Kit skills (`/speckit-*`). Execution phase: Superpowers skills. Do not use Superpowers brainstorming or writing-plans: the Spec Kit artifacts replace them.
- A PostToolUse hook runs typecheck + tests after every .ts/.tsx edit. Failures during the RED step of TDD are expected.
- Show the commit message and wait for approval before every commit.
