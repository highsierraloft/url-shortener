# Transcript exports

These files contain the visible user and assistant messages from the two referenced threads, in time order. They exclude tool output and internal reasoning.

Privacy review redacted local home paths, email addresses, IP literals, local hostnames, and thread identifiers. The exported messages were also scanned for common credential formats; none remained in the final files.
